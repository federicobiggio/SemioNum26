## 5.2 Designing an ARF with Lens Studio

Dans cette seconde partie, les étudiants concevront et prototyperont des filtres de Réalité Augmentée (ARF) dans Lens Studio. 

Chacun peut concevoir l'ARF qu'il préfère, en fonction de ses compétences informatiques. Voir: https://developers.snap.com/lens-studio/4.55.1/references/templates/overview  

En principe, tout le monde doit faire ces deux ARF: 

1 ARF mask with open mouth : dans camera object mettre "Face mask" (camera object > effects > face mask); sous face mask mettre "behaviour". 2 behaviour: trigger = face event; event type = mouth opened; response type=set enabled; entity type=component; target component=face mask (à changer comme vous voulez); response type=set enabled; action=enabled; Le deuxième behaviour doit être défini pour la bouche fermée, comme dans l'image.

1 ARF de type “blink ranking” (dossier ARF2 sur celene) : un micro-jeu interactif simple utilisant le clignement (ou un geste facial similaire) comme input, avec une logique de score/classement basique et des indices de feedback.  

Suivre ce tutoriel : https://www.youtube.com/watch?v=MqI0BKL-HR0&t=2s

Livrables : les 2 (ou plus) prototypes Lens Studio fonctionnels (capture vidéo de l’écran) accompagné d’une courte note technique documentant les templates choisis, les réglages clés et la logique d’interaction.
