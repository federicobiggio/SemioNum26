# TD 1

## Analyse computationnelle d’images

Créer une visualisation des couvertures de Wired selon les valeurs de teinte, de luminosité et de saturation.

La base de données se trouve dans le dossier "wired_cover" (dans "Ressources/TD1")

Créer la visualisation avec 2 processus :
	1. avec https://ereyes.github.io/drag_and_hue/, outil Plot (tester aussi Listmaker)
	2. avec HTML, CSS, JS : exécuter e09-getJSON.html (dans le dossier "scripts_wired", dans "Ressources/TD1") en local avec MAMP/XAMPP (ne pas oublier d’inclure jquery-3.7.1.min.js)

Pour aller plus loin : tester aussi e06-getJSON.html et e07bis-getJSON.html (dans le dossier « plus »).
