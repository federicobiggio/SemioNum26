## Interfaces gestuelles et visuels dynamiques

### Phase 1 — Le geste comme signe (20 min, individuel)

Chaque étudiant choisit deux applications de son téléphone et remplit le tableau suivant pour au moins quatre gestes par application.

| Application | Geste | Localisation | Action déclenchée | Motivé ou conventionnel ? |
|---|---|---|---|---|
| | Tap | | | |
| | Swipe | | | |
| | Long Press | | | |
| | Double Tap | | | |
| | Pinch | | | |
| | Drag & Drop | | | |


La cinquième colonne est la plus importante. Pour chaque geste, répondre à la question : ce geste est-il motivé — c'est-à-dire fondé sur une analogie perceptive avec un geste du monde physique — ou est-il purement conventionnel, c'est-à-dire appris par usage sans ancrage dans une expérience corporelle antérieure ?

Exemples pour amorcer la réflexion :

Le pinch pour zoomer est motivé : il mime l'écartement de deux doigts sur une surface physique.
Le swipe vers le haut pour scroller est plus ambigu : dans quel sens "monte-t-on" réellement ?
Le long press pour accéder aux options est purement conventionnel : rien dans la durée d'appui ne ressemble naturellement à un menu caché.

### B — La métaphore spatiale mobilisée

Toute animation de scroll construit implicitement une métaphore de l'espace : l'utilisateur se déplace dans un espace, ou le contenu se déplace devant lui. Ces deux options ne sont pas équivalentes sémiotiquement.

Répondre aux questions suivantes :

Qui bouge — l'utilisateur ou l'objet ?
Dans quelle direction spatiale le scroll produit-il un déplacement ? (vers le bas, vers l'intérieur, vers le passé, vers la profondeur ?)
Le mouvement imite-t-il un mouvement de caméra identifiable ? Si oui, lequel : travelling avant, panoramique, zoom, plongée, contre-plongée ?
Quels autres langages ou genres ce mouvement évoque-t-il : cinéma, diaporama, livre qui se tourne, défilement de pellicule, descente physique ?

### C — Effet sur l'organisation de l'information

L'animation n'est pas seulement décorative — elle produit une hiérarchie temporelle de l'information : certains éléments apparaissent avant d'autres, certains persistent pendant que d'autres disparaissent.

L'animation guide-t-elle la lecture dans un ordre précis, ou laisse-t-elle l'utilisateur libre de son parcours ?
Est-elle pertinente pour le type d'information représentée — c'est-à-dire : le mouvement ajoute-t-il du sens, ou est-il purement stylistique ?
